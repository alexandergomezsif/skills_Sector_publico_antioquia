# Glosario de gestión pública departamental

| Término | Significado |
|---|---|
| Apropiación | Monto autorizado en el presupuesto para un rubro y vigencia (Decreto 111 de 1996). Inicial y definitiva (tras adiciones, reducciones, traslados). |
| CDP | Certificado de Disponibilidad Presupuestal: garantiza que existe apropiación libre antes de comprometer. |
| RP / Compromiso | Registro Presupuestal: perfecciona el compromiso y afecta la apropiación de forma definitiva. Requisito de ejecución del contrato. |
| Obligación | Monto exigible por bienes/servicios recibidos (cumplido a satisfacción). |
| Pago | Giro efectivo de tesorería. |
| Reserva presupuestal | Compromisos al 31 de diciembre sin obligación; se ejecutan en la vigencia siguiente. |
| Cuenta por pagar | Obligaciones al 31 de diciembre pendientes de pago. |
| Vigencia futura | Autorización para comprometer presupuesto de vigencias siguientes (Ley 819 de 2003, arts. 11-12; Ley 1483 de 2011 para territoriales). |
| PAA | Plan Anual de Adquisiciones (Decreto 1082 de 2015, art. 2.2.1.1.1.4.1 y ss.). |
| SECOP II | Sistema Electrónico de Contratación Pública. |
| RUP | Registro Único de Proponentes (Cámaras de Comercio). |
| Estudios previos | Documento de planeación del contrato (art. 2.2.1.1.2.1.1 Decreto 1082). |
| Análisis del sector | Estudio de mercado, oferta y demanda (art. 2.2.1.1.1.6.1 Decreto 1082). |
| Matriz de riesgos | Identificación, tipificación, estimación y asignación de riesgos previsibles (art. 4 Ley 1150; Manual CCE). |
| Supervisor / interventor | Seguimiento técnico, administrativo, financiero, contable y jurídico del contrato (arts. 83-84 Ley 1474 de 2011). |
| Liquidación | Corte de cuentas final (art. 11 Ley 1150; art. 60 Ley 80). |
| Urgencia manifiesta | Causal de contratación directa (art. 42 Ley 80). |
| MGA | Metodología General Ajustada para proyectos de inversión (DNP). |
| BPID | Banco de Programas y Proyectos de Inversión Departamental. |
| POAI | Plan Operativo Anual de Inversiones. |
| Plan de Acción | Instrumento anual por dependencia que concreta metas del plan de desarrollo (Ley 152 de 1994, art. 41). |
| MIPG | Modelo Integrado de Planeación y Gestión (Decreto 1499 de 2017). FURAG: formulario de reporte. |
| PTEP | Programa de Transparencia y Ética Pública (Ley 2195 de 2022, art. 31). |
| PQRSDF | Peticiones, quejas, reclamos, sugerencias, denuncias y felicitaciones. |
| TRD / TVD | Tablas de Retención / Valoración Documental (Ley 594 de 2000). |
| SGR | Sistema General de Regalías (Ley 2056 de 2020). |
| SMMLV | Salario mínimo mensual legal vigente. |
| UVT | Unidad de Valor Tributario. |
